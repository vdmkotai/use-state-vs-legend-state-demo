# Legend State vs React useState Demo 🎮

A simple demo comparing how Legend State and React's useState handle forms.

Notes:
- React Strict Mode is off (no more double renders!)
- Want performance stats? Uncomment `react-scan` in index.html

## Getting Started

You'll need [Bun](https://bun.sh/) installed first.

### Quick Start

1. Clone it:
   ```bash
   git clone <this-repo>
   ```
2. Install stuff:
   ```bash
   bun install
   ```
3. Run it:
   ```bash
   bun dev
   ```
4. Check out `http://localhost:5173` 🚀
